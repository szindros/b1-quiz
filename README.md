# Κουίζ Πιστοποίησης Β1 ΤΠΕ – Κλάδος ΠΕ02 (Φιλόλογοι)

Διαδραστική διαδικτυακή εφαρμογή προσομοίωσης και αυτοαξιολόγησης για τις εξετάσεις **Πιστοποίησης Β1 Επιπέδου στις Ψηφιακές Τεχνολογίες (ΤΠΕ)** (ΙΤΥΕ «Διόφαντος») ειδικά για εκπαιδευτικούς του κλάδου **ΠΕ02 (Φιλολόγων)**.

## Περιεχόμενο
* **10 Ερωτήσεις Πολλαπλής Επιλογής**
* **10 Ερωτήσεις Σωστού / Λάθους**
* **5 Ερωτήσεις Σύντομης Απάντησης** (με αυτόματο έλεγχο λέξεων-κλειδιών, πρότυπες απαντήσεις και αυτοαξιολόγηση)
* Άμεση ανατροφοδότηση και παιδαγωγικές επεξηγήσεις σε κάθε ερώτηση.
* Εναλλαγή φωτεινού/σκοτεινού θέματος (Light/Dark Mode) και δυνατότητα τυχαίας αναδιάταξης ερωτήσεων.
