# Τράπεζα 100 Ερωτήσεων Πιστοποίησης Β1 ΤΠΕ – Συστάδα Β1.1 (Φιλολογικά)

Διαδραστική διαδικτυακή εφαρμογή αυτοαξιολόγησης για εκπαιδευτικούς κλάδου **ΠΕ02 (Φιλόλογοι)** που προετοιμάζονται για τις εξετάσεις πιστοποίησης **Β1 Επιπέδου στις Ψηφιακές Τεχνολογίες (ΤΠΕ)**.

Βασισμένη εξ ολοκλήρου στο επίσημο **Ενιαίο Τεύχος Επιμορφωτικού Υλικού (Συστάδα Β1.1 Φιλολογικά – Έκδοση 6η, Φεβρουάριος 2026, ΙΤΥΕ «Διόφαντος» & ΙΕΠ)**.

## Περιεχόμενο (100 Ερωτήσεις στις 12 Συνεδρίες)
* **40 Ερωτήσεις Πολλαπλής Επιλογής** (με άμεση επεξήγηση και παραπομπή σε συνεδρία/σελίδα)
* **35 Ερωτήσεις Σωστού / Λάθους** (με αιτιολόγηση και παραπομπή σελίδας)
* **25 Ερωτήσεις Συμπλήρωσης Κενών** (με αυτόματο έλεγχο ανεξαρτήτως τόνων/πεζών-κεφαλαίων και εμφάνιση λύσης)
* Φίλτρα ανά κατηγορία ερωτήσεων, επιλογέας γρήγορης μετάβασης σε οποιαδήποτε ερώτηση (1–100), ανακάτεμα ερωτήσεων και εναλλαγή φωτεινού/σκοτεινού θέματος (Light/Dark Mode).
